Đối chiếu 5 đặc tính NIST

  1. Tự phục vụ theo yêu cầu: tôi tự bấm Create codespace trên GitHub và có máy ảo chạy sau [X] giây, không cần ai phê duyệt hay cấp phát thủ công.
  2. Truy cập mạng rộng: tôi chuyển cổng 3000 sang Public và mở được API trên điện thoại qua URL https, chỉ cần trình duyệt và internet.
  3. Gộp tài nguyên: máy ảo của tôi (hostname codespaces-ac4b0b, 2 CPU, 7.8 GB RAM, nhân Linux azure) được cắt ra từ kho máy chủ dùng chung của GitHub trên hạ tầng Azure, phục vụ nhiều người dùng cùng lúc.
  4. Co giãn nhanh: có thể tạo thêm codespace hoặc đổi cấu hình máy (ví dụ lên 4 hoặc 8 nhân) chỉ bằng vài cú bấm, và dừng hoặc xóa khi không cần.
  5. Dịch vụ đo lường được: mục Billing → Usage của GitHub ghi lại số core-giờ Codespaces tôi đã dùng: [X] core-giờ.
